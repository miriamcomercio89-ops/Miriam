Orbis Hotels Group

El ZIP del juego (orbis-hotels-group-juego.zip) se abre a doble clic: descomprime y abre index.html.

Opción rápida — ZIP offline

  1. Descarga orbis-hotels-group-juego.zip
  2. Descomprímelo
  3. Doble clic en index.html

Ese ZIP usa JavaScript clásico (sin type="module"). Generar de nuevo: npm run pack:juego.

Opción desarrollo

  1. npm install
  2. npm run dev
  3. Abre la URL (suele ser http://localhost:5173)

Generar el ZIP offline

  1. npm run build:offline
  2. La carpeta offline/ ya se puede abrir a doble clic
