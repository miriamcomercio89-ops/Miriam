Orbis Hotels Group

No abras el index.html haciendo doble clic en el archivo: el juego necesita un servidor (o la carpeta dist/ servida).

Opción A — desarrollo

  1. npm install
  2. npm run dev
  3. Abre la URL que salga (suele ser http://localhost:5173)

Opción B — versión compilada

  1. npm run build
  2. npx serve dist (o cualquier servidor estático)
  3. Abre la URL que indique el servidor

Si ya tienes dist/ generado, prueba el botón de abajo (solo funciona si abres esta página a través de un servidor, no como archivo local).
