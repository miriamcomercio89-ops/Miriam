Descarga: [saborama_atlas_completo.zip](https://media.githubusercontent.com/media/miriamcomercio89-ops/Miriam/cursor/meridiano-imperio-gastronomico-d2e2/descargas/saborama_atlas_completo.zip)

Los PDF del atlas todavía usan la nomenclatura anterior. El simulador ya es **Horizon Restaurant Group** y las 50 marcas nuevas; el atlas se regenerará en una pasada siguiente.

Cada carpeta de cabecera cubre el pueblo **y los municipios de alrededor** (~26 km).
Ejemplo: `España / Andalucía / Málaga / Coín` incluye Guaro, Monda, Alozaina…
Álora y Pizarra están en la zona de **Cártama**.

Ruta actual: `País / CCAA o estado / provincia / cabecera / Saborama_….pdf`
