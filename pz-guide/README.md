- Sandbox · población alta · sin respawn · migración sí

## Generar PDFs

```bash
pip install reportlab pypdf
python3 src/generate_all.py
```

Salida en `output/`. Empaquetado: `PZ_B42.20_Guia_Limpieza_Total.zip`.
