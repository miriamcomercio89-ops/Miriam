# Loterías Álora

Simulador realista de administración de loterías en **Álora**. Tú eres **Miriam**.

**Versión: 0.3**

## Cómo jugar

1. Descarga el ZIP del juego  
2. Abre **`LOTERIAS-ALORA.html`** (doble clic)

No abras `index.html` de la raíz.
