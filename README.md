# Loterías Álora

Simulador realista de una administración de loterías en **Álora** (Málaga). Tú eres **Miriam**, la única empleada.

**Versión actual: 0.1.1**

## Cómo jugar (lo más fácil)

1. Descomprime el ZIP  
2. Abre el archivo **`ABRE-EL-JUEGO.html`** con el navegador (doble clic)

También puedes abrir `jugar/index.html`.

> No abras el `index.html` de la raíz para jugar: ese es solo para desarrollo con Vite y sale en blanco sin servidor.

## Desarrollo (opcional)

```bash
npm install
npm run dev
```

Para regenerar la versión jugable sin servidor:

```bash
npm run build:play
```

## Novedades v0.1

- Sorteos automáticos: Lotería Nacional, Primitiva, Bonoloto, Euromillones, Cupón ONCE
- Tickets con números; clientes vienen a **comprobar** si ha tocado
- Pagar premio al momento, dejarlo para otro día, o **gestión** de premios grandes
- **10 rascas** bien definidos
